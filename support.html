DoTheDeed helps you record completed activities with a time and place, explore your activity, and keep a backup of your records. It requires iOS 17 or later on iPhone.

Getting started

Open the app and rename “My first thing” with the pencil button, or create an event from the sidebar. Tap Done and allow location access to save a record. Expand the bottom panel to switch between Records and Stats.

Location is unavailable

Check Settings → Privacy & Security → Location Services and allow DoTheDeed access while using the app. Location can be unavailable indoors or when the device cannot obtain a fix. Existing records remain available when location is disabled; manual location entry is not currently supported.

A place name is missing

A record can be saved with coordinates before its place name is available. Map loading and place-name lookup may need an internet connection. Reopen the app with a connection or use the retry option where shown.

Why do I see only a few statistics?

Stats adapt to your records. Additional modules appear as enough relevant data becomes available. Map cells represent recorded places, not complete route histories or coverage percentages.

Managing events

Up to three events can be active. Long-press an event to archive it and retain its records, then create another. Restore archived events from the sidebar when an active slot is available.

Language

Open the sidebar and choose Language to select English, Simplified Chinese, or the device setting. Restart the app when prompted.

Backing up and moving devices

Use Export backup in the sidebar to save a JSON file. Keep it in a trusted location before removing the app or changing devices. Use Import backup to merge a compatible backup. The app does not automatically sync between devices. Export files contain location and timestamp details, so keep them private.

Deleting records

Swipe left or long-press a record to delete it. Archiving an event does not delete its records. Removing the app deletes its local data; exported copies and device backups must be managed separately. The developer cannot restore records that are no longer on your device or in a backup you control.
